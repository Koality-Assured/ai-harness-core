## Operational Usage

When researching model capabilities, context window limits, token pricing, or prompt caching features:
1. Always consult the official developer documentation portal first.
2. Verify release dates and model identifiers against official release notes.
3. Reject secondary blog claims regarding model performance unless backed by official vendor technical reports or reproducible evaluation runs.
