# ast-grep

Human intro for [ast-grep](https://ast-grep.github.io/) in this repo — precision retrieval for Python, JSON, and YAML (including Markdown YAML frontmatter).

**Agents:** durable patterns live in [`precision-retrieval.md`](./precision-retrieval.md). Do not use this README as operating procedure — root [`../../AGENTS.md`](../../AGENTS.md) High README rule.

Quick install (Windows, this machine): `python -m pip install ast-grep-cli` then `ast-grep --version` (expect 0.45.1). Python `Scripts\` must sit on PATH ahead of WindowsApps — same ordering as [`../workstation-onboarding.md`](../workstation-onboarding.md).
