# Diagramming support

This folder owns durable guidance for choosing and maintaining diagram formats, in addition to [`supporting/AGENTS.md`](../AGENTS.md).

- Keep the evidence-backed selection policy in [`format-selection.md`](./format-selection.md).
- Keep Mermaid CLI details in [`../mermaid/`](../mermaid/); link to vendor documentation instead of duplicating tool manuals.
- State which claims are vendor-documented and which are recommendations inferred from the editing models. Do not present an unmeasured preference as a benchmark.
