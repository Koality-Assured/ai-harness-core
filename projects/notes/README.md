# Project notes

Human-requested informal thoughts, memos, and follow-up items that have **not** yet been established as formal initiative specs or had planning done beyond a vague note. Formal initiative specs stay under flat `projects/<slug>/README.md`.

| Rule | Detail |
| --- | --- |
| Who creates | Human request only — agents do not invent notes here |
| Naming | One concern per kebab-case file; `YYYY-MM-DD-short-intent.md` OK |
| Not for | Chronicles, research dumps, durable standards, or `actionable/` intake |
| Promotion | When a note receives concrete scoping or becomes active work, promote to `projects/<slug>/` |
