# Writing patterns (anti-slop)

Improved extract from public baselines ([no-ai-slop](https://github.com/petergyang/no-ai-slop), [anti-ai-slop-writing](https://github.com/jalaalrd/anti-ai-slop-writing)). Advisory — follow [`../../../../docs/anti-slop.md`](../../../../docs/anti-slop.md).

## Edit principles

- Minimum effective edit; preserve voice and claims.
- Lead with the point; cut throat-clearing and summary-recap endings.
- Concrete facts, mechanisms, named sources over weasel attribution.
- Vary sentence length and structure; no uniform mid-length cadence.
- Portability test: if a sentence could move to any product unchanged, cut or make specific.
- Never invent stats, quotes, anecdotes, or sources.

## Patterns to cut

| Pattern | Tell | Fix |
| --- | --- | --- |
| Binary contrast | “Not X, it’s Y” | State Y |
| Throat-clearing | “Here’s the thing,” “It’s worth noting” | Start the claim |
| Faux insight | “What most people miss…” | Drop the flattery setup |
| Colon drama | Noun phrase + colon + reveal | Plain sentence |
| Superficial *-ing* | “highlighting…”, “underscoring…” | Real consequence or cut |
| Importance puffery | “pivotal moment”, “vital role” | Fact only |
| Weasel attribution | “experts say”, “studies show” | Name source or cut |
| Synonym cycling | agent/assistant/tool for one thing | One clear name |
| Rule of three | Forced triads | 1, 2, 4, or uneven |
| Parataxis stack | Short. Blunt. Stack. | Connect with clauses |
| Em-dash addiction | Decorative dashes | Comma, period, paren |
| Formatting slop | Emoji headings, mid-sentence **bold** | Prose does the work |
| Chatbot leftover | “Certainly!”, “I hope this helps”, “As an AI…” | Delete |
| Fake-profound kicker | Mic-drop metaphor ending | End on concrete takeaway |
| Summary ending | “In conclusion,” restating paragraph | Cut; end on last useful point |

## Structure

- No identical paragraph template (topic → explain → example → transition) on every block.
- Bullets sparingly; prefer prose when two sentences suffice.
- Active voice with human subjects when clearer.
- Contractions OK in informal deliverables; match audience.
