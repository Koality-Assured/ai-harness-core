# Model memory AGENTS

Model-family evidence that survives across hosts without becoming a host configuration log. Cross-reference `../user/<git-identity>/` for workstation/runtime facts and `../agent/<owner_agent_id>/` for specialist execution facts.

## Successful capability execution

Record only a proven model-family capability, the minimal reproducible method, evidence command or artifact, scope, and a link to the relevant user or agent memory when host context mattered.

## Unavailable or failed capability

Record only a proven unavailable or failed model-family capability, the failure boundary, evidence command or artifact, recovery or fallback, and a link to the relevant user or agent memory when host context mattered.

Do not add other durable categories, session logs, credentials, personal paths, model-picker IDs, or copied user/agent memory. Spawn `memory-operator` for `model-memory-operate` (retrieval, deduplication, and promotion after validation) — not `ai-tooling-ops`.
