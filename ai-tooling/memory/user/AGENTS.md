# User memory AGENTS

Human/workstation checkpoints. One folder per person, keyed by stable Git/GitHub identity.

## Rules

- Folder slug: lowercase GitHub login (or other stable unique id). Example: `distastefu1`.
- Create the folder during workstation onboarding ([`../../../supporting/workstation-onboarding.md`](../../../supporting/workstation-onboarding.md)).
- Store session and workstation oddities here (PATH, tool versions, host quirks). No secrets.
- Display name inside files may be the human’s preferred name; folder id stays the git identity.
- Prefer one primary checkpoint file per user (e.g. `workstation.md`); add more only for distinct multi-session threads.
- Nested AGENTS only here — do not paste root Critical.
